# raytracing_engine (WIP)

This project is a raytracer built from scratch, focused on exploring and understanding the fundamentals of physically-based rendering and modern graphics techniques.

## Project Status

**Work in Progress (WIP)**

The project is currently under active development. Many features are incomplete or still being improved.

## Current Features

* Basic ray tracing rendering
* Support for **diffuse (Lambertian) materials**
* Ray-object intersection handling (triangular meshes)
* Core structures for materials and scene objects

## In Progress

* More advanced materials (reflective, refractive, metallic)
* Improved sampling
* Performance optimizations
* Support for additional geometry types
* Better Doc
* BVH hierachy


## Technologies

* C++
* OpenCL 
* OpenGL 

## Notes

This project is intended as an experimental and learning-oriented codebase (for myself), so expect frequent changes and refactoring, also im trying to not use AI for learning purposes.

If you're interested in ray tracing or low-level graphics programming, this repository can serve as a starting point

## Build & Run
Prerequisites (I have tested only Windows):
- glfw3
- GLEW
- CMake >= 3.20
   
Build using CMake and then in the build folder search for src/ocl_glfw.exe
